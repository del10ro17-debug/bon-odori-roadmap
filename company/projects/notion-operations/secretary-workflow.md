# 秘書運用フロー

Notion連携後、CEOは基本的にCOOへ依頼する。COOが秘書・PMO・ITへ振り分ける。

## よく使う依頼

### 議事録を作る

CEO:

```text
COO、以下のメモを議事録にして。Notionの議事録DBに入れる前提で、決定事項とToDoを分けて。
[メモ]
```

出力:

```markdown
【COO】
- 担当: 秘書
- 保存先: Notion `議事録`

【秘書】
## 議事録
...

## タスク化する項目
...
```

### 来週の予定を整理する

CEO:

```text
COO、来週の予定を整理して。準備タスクが必要なものを洗い出して。
```

出力:

```markdown
【COO】
- 担当: 秘書 / PMO

【秘書】
## 来週の予定
...

## 準備タスク
...
```

### 盆踊りの運営会議を整理する

CEO:

```text
COO、盆踊りMTGのメモをNotion用の議事録にして。Event Opsの観点でリスクも出して。
```

出力:

```markdown
【COO】
- 担当: Event Ops / 秘書

【Event Ops】
## 決まっていること
...

【秘書】
## 議事録
...
```

## 議事録の品質基準

- 決定事項、ToDo、CEO確認事項を分ける。
- 固有名詞、日付、金額が曖昧な場合は `要確認` と書く。
- ToDoは「担当」「内容」「期限」「関連プロジェクト」に分ける。
- Notionに保存する前に、個人情報や認証情報が入っていないか確認する。

## Notion保存前チェック

| チェック | 内容 |
|----------|------|
| 秘密情報 | APIキー、パスワード、口座情報が含まれていない |
| 個人情報 | 必要以上の個人情報がない |
| 決定事項 | CEOが確定した内容だけになっている |
| ToDo | 担当と期限がある。未定なら `要確認` |
| 関連 | プロジェクトIDが入っている |
