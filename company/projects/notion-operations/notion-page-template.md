# 会社HQ

このページは、仮想会社HQのスケジュール、議事録、タスクを管理するNotion本社です。

## 主要DB

- 議事録
- タスク
- 予定
- プロジェクト

## 今日見る場所

1. `タスク` の `今日やる`
2. `予定` の `今週`
3. `議事録` の `最近`

## COOへの依頼例

```text
COO、今日の会議メモをNotion用の議事録にして。決定事項とToDoを分けて。
```

```text
COO、NotionのタスクDBを前提に、今週やることを担当別に整理して。
```

```text
COO、盆踊りMTGのメモをEvent Ops視点で整理して、タスクDBに入れる項目も出して。
```

## 保存ルール

- 確定事項は `議事録` または `プロジェクト` に残す。
- 実行することは `タスク` に残す。
- 日時があるものは `予定` に残す。
- APIキー、パスワード、口座情報は保存しない。
