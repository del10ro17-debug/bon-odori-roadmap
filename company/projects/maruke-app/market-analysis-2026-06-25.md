- 作成: 2026-06-25

- ミッション: **全ての子供に学習機会を** — 高所得層以外にも、丸つけ経由で弱点・伸び代を見せ、最短距離のレベルアップを

## 1. エグゼクティブサマリー

| 論点 | 結論 |
|------|------|
| 市場はあるか | **ある**。EdTech・採点AIは成長中。宿題丸つけは「点」で既に複数プレイヤー |
| 隙間はあるか | **ある**。ただし「競合ゼロ」ではなく **ポジションの空き**（使命・受験深度・コーチング・信頼設計） |
| 採点くんとの関係 | 同カテゴリの **直接競合**。機能で殴るより **誰の学習機会か** で差別化 |
| 勝ち筋 | 低価格で採点ログを溜め → 弱点・伸び代 → 最短ルート提示。**塾の代替ではなく学習機会のインフラ** |

### 2-4. SAM / SOM（ざっくり）

**SAM（到達可能市場）:** 宿題丸つけを親が週1回以上する小学生家庭

- 581万児童 × 保護者が丸つけ担当 ≒ **300〜400万世帯**（仮）

**SOM（3年で現実的に取れる市場）:** 中学受験＋一般小学生の「デジタルに慣れた保護者」

- 有料転換 **5〜10万世帯** × 月600円 ≒ **年3.6〜7.2億円**（上限シナリオ）
- 認知・継続・無料代替（ChatGPT手動）で **1/10以下** が現実的な初年度

## 3. 競合マップ（5レイヤー）

```
[L5] 塾・通信教育（年数十万〜百万）— 指導・カリキュラム・仲間
[L4] 成績管理・コーチ（月数百〜数千）— マトミル、リロ模試
[L3] 学習・質問アプリ（月0〜2千）— StudyCast, QANDA, Uknow
[L2] 採点・丸つけ（月0〜1.8千）— 採点くん, Uknow, MITORU(算数)
[L1] 手動・代替（無料）— 親の手丸つけ, ChatGPTコピペ
```

**まるつけの射程:** L2 から L4 へ伸ばす（採点ログ → 弱点 → 最短ルート）。

## 4. 採点くん バリューポジション（深掘り）

**提供元:** INEXUS INC.（港区）｜2025年4月リリース｜iPhone/iPad

### 4-1. Jobs-to-be-done

| ジョブ | 採点くんの約束 |
|--------|----------------|
| 機能的 | 撮影 → 自動丸つけ → 解説 → 履歴で苦手把握 |
| 感情的 | 「夕方を子どもとの時間に」「教えられない問題も子が進める」 |
| 社会的 | 「良い親・効率の良い家庭学習」（暗黙） |

### 4-2. プロダクト分解

| 要素 | 内容 |
|------|------|
| モード | 自動丸つけ / 問題解答（解説） |
| AI | 標準（速い）/ 高度（詳細分析） |
| 教科 | 算国理社英・小中学生 |
| 撮影 | 1枚（無料）/ 連続（Pro以上） |
| 料金 | Free / **Pro 600円** / Premium **1,800円** |

### 4-3. 口コミから見る強み・弱み

**強み（★4〜5）**
- 答え用紙がない問題集で重宝
- 親の時短・計算ミス削減
- 子どもが「機械に合わせて字を書く」モチベーション

**弱み（★3以下・離脱要因）**
- **漢字・文章の採点がずれる**（○×の位置ミス、採点してほしい箇所と違う）
- 期待と精度のギャップでがっかり
- → **最終確認は親** が推奨される類のアプリ

### 4-4. 採点くんが言っていないこと

- 教育格差・「みんなに機会を」という **社会使命**
- 中学受験 **プリント特化**（進研/Z会/塾形式）
- **誤採点を避ける** 明示設計（🟡委譲）
- **未記入→解答例** の一フロー統合
- 「最短距離のレベルアップ」までの **コーチング物語**

## 6. Codex 実装ログから見た市場仮説（技術×UX）

Codex で `maruke-app` を試作した知見:

| 仮説 | 検証結果 |
|------|----------|
| 親は「3秒採点」を期待 | 実測 **7〜14秒**（29問見開き）。期待調整が必要 |
| 全学年・全教科一括 | 見開き・多問は **JSON truncation・読み取りミス** |
| 空欄→解答例 | **プロンプトで可能**。差別化の核として有効 |
| デモfallback | 信頼毀損。**実採点 or 明示デモ** が必須 |
| 学年別モデル切替 | 小5〜6は精密モデル必要。コストと精度のトレードオフ |

**市場示唆:** 「一瞬・全問・全教科」を売ると採点くん口コミと同じ **精度失望** に落ちる。売るべきは **信頼できる採点＋次の一歩**。

## 7. 教育格差とミッションの接続

| データ | 意味 |
|--------|------|
| 低所得世帯の塾参加率低 | 塾＝学習機会の入口が閉じている |
| 高所得は塾代を増やす、低中所得は削る | 格差は拡大方向 |
| 経済困窮家庭43%が塾・習い事なし、9割が経済理由 | **安価ツールの需要は構造的** |
| 貧困世帯の学力格差は小4頃から拡大（研究） | 低学年からの **家庭学習の質** が効く |

**まるつけの社会価値仮説:** 月数百円で「採点＋弱点の見える化」まで届ければ、**塾に行けない家庭の学習密度**を上げられる（指導・仲間は別途）。

| 次元 | 採点くん | まるつけ（提案） |
|------|----------|----------------|
| **使命** | 親の時短・子の自学 | **全子どもに学習機会** |
| **約束** | 宿題チェック完結 | 丸つけ → **弱点・伸び代 → 最短ルート** |
| **信頼** | ○×即決（口コミで精度不満） | **🟡で親に委譲**（誤採点回避） |

| **価格の物語** | 月600円で便利 | **塾年110万のうち採点・見える化を年1万以下で** |
| **データ** | 履歴・苦手（あり） | ログ → **単元別コーチング**（これから） |

### 差別化の一文（案）

> **塾に行えない家庭にも、受験レベルの「丸つけと次の一歩」を。月数百円で。**

## 9. 国語「記述」— 市場上の位置

（「指紋」ではなく **記述（きじゅつ）**）

- **記述:** 読解文を読み、自分の言葉で短く書く問題。親が丸つけ困難。
- **競合:** アレイが **受験国語記述に特化**（要素分解・声かけ・β月60回無料）。
- **採点くん:** 口コミで **漢字・文章採点の不満** — 国語は勝負所。
- **まるつけ戦略:** P0は記述を **🟡＋解答例＋観点**。P1で要素分解。アレイと **正面衝突せず**「毎日の全教科入口」から入る。

## 10. 脅威・リスク

| リスク | 内容 |
|--------|------|
| 採点くんの先行者 | 同機能・低価格・App Store 露出 |
| 大手参入 | ベネッセ・教育同人社（MITORU）の学校→家庭展開 |
| ChatGPT無料化 | 親の手動代替が「十分」になる層 |
| 精度失望 | 見開き・記述で誤採点 → 口コミ悪化（採点くんと同型） |
| APIコスト | 多問・高精度モデルで単価悪化 |
| 規制・未成年 | 子ども直接利用 vs 親代理の線引き |

## 11. 戦略オプション（3案）

### A. ミッション先導（推奨）

- 訴求: **学習機会の平等**
- 価格: 基本無料 or 低価格＋コーチング課金
- 採点くんと **カテゴリを変える**（ツール vs インフラ）

### B. 受験特化

- 訴求: 中学受験家庭の毎晩丸つけ
- アレイ・マトミルと **機能で棲み分け**（採点 vs 記述 vs 成績）

### C. 採点くん同型で勝つ

- 全教科・月600円・弱点分析
- **非推奨** — 先行者・口コミ・ASOで不利

---

## 12. 次のアクション（CEO / プロダクト）

1. **戦略オプション A or B** を選ぶ（ミッション広げ vs 受験特化）
2. **P0の約束を絞る** — 「全範囲完璧」ではなく「4教科・片ページ・信頼できる丸つけ」
3. **採点くんを1週間実使用** — 漢字・国語・見開きでギャップを体感
4. **価格仮説** — 無料＋広告なし＋コーチング817円級？
5. **ログ設計** — 弱点分析のデータモデル（単元タグ）を早期定義
