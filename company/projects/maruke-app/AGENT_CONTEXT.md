# まるつけ — Agent Context

## 一言

**中学受験家庭向け**の宿題丸つけ。撮影→答え合わせ→（将来）弱点・最短ルート。塾市場の「親の丸つけ＋見える化」から食いに行く。

## ミッション

全ての子供に学習機会を — 実ターゲットは **中学受験の丸つけ**。塾月10万の代替ではなく、**家庭学習の質を塾級に**。

## ユーザーフロー（P0）

1. 学年（小4〜6）・教科を選ぶ
2. 塾・進研・Z会の答案を撮影（片ページ推奨）
3. 任意で解答ページを添付
4. ⭕️❌🟡 または ✏️解答例

## 採点ルール（必須）

- 解答ページあり → `basis=answer_key`
- 手書きあり → `result_type=graded`
- 未記入 → `result_type=answer_example`
- 読めない / 記述 → `uncertain`、勝手に×にしない
