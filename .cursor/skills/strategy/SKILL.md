# 戦略

- 市場・競合の整理（仮説と事実の分離）

- KPI / OKR の案とトラッキング表

## 手順

1. handbook のミッション・制約を読む
2. **問い** を1文で定義
3. 2〜3案を比較 → 推奨とリスクを明示
