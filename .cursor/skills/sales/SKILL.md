# 営業

## 担当範囲

- 顧客・商談メモの構造化
- 提案書・見積の骨子と文案
- パイプライン（ステージ・確度・次アクション）
- フォローメール・議事録の営業視点サマリ

## 手順

1. `company/handbook.md` の価格方針・ターゲットを確認
2. 顧客の課題・決裁者・競合を整理
3. 提案の **価値 → 根拠 → 次の一歩** で出力

-

## 提案骨子テンプレート

1. エグゼクティブサマリ（3行）
2. 現状と課題
3. 提案内容・スコープ
4. 効果・ROI（仮説は明示）
5. スケジュール・価格
6. 次のステップ（CTA）

## 品質基準

- 競合他社名は事実ベース。推測は「仮説」とラベル
- 割引・特別条件は **CEO 承認待ち** と明記
