    ケバブ原価（食材）

    材料原価・販売単価を変えると粗利と売上試算がその場で再計算されます（確定メニュー700円のまま試す場合は単価を変えなくてOK）。

    ドリンク原価・販売単価

    4種それぞれの仕入単価と販売単価を入力できます。売上試算では平均原価・平均販売単価を使います。

    試算の前提

    「売上試算」タブの計算に使う設定です。

    売上目標と販売数量比率を入力すると、販売数と仕入れ量を自動計算します。単価は「原価」タブで変更できます。

    売上・仕入れ試算

    売れる個数のうち、何%がケバブか（例: 80%なら10個中8個がケバブ）。ドリンク添えは少数、という想定です。
